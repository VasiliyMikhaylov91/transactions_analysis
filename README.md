# Учебный проект для Skypro для курсовой работы "Анализ транзакций Т-банка"

## Описание
Проект создан на языке Python в среде PyCharm использованием менеджера пакетов Poetry в соответствии с учебной задачей Skypro с образовательной целью. Реализованы функции для анализа транзакций и некоторый полезный функционал в финансовой сфере.

## Установка
1. Установите PyCharm c официального сайта JETBRAINS [Ссылка на сайт](https://www.jetbrains.com/pycharm/.)
2. Установите менеджер пакетов Poetry [Ссылка тут](https://python-poetry.org/)
3. В PyCharm склонируйте репозиторий с ссылкой https://github.com/VasiliyMikhaylov91/transactions_analysis
4. Установите интерпретатор Python Poetry
5. Установите необходимые зависимости описанные в файле pyproject.toml
6. Для работы с модулем utils необходимо получить ключ API с https://apilayer.com/marketplace/exchangerates_data-api и https://www.alphavantage.co/support/ Создать файл .env в соответствии с .env.example

## Запуск программы
Запуск программы осуществляется из файла main.py.
## Описание функций
Основные функции находятся в пакете src

В модуле utils:
- Функция read_xlsx_transactions принимает на вход путь к .xlsx файлу с транзакциями из личного кабинета Т-банка по умолчанию data/operations.xlsx и предоставляет список словарей с транзакциями из файла
- Функция create_dt_obj принимает строку в формате "%d.%m.%Y %H:%M:%S" и создает объект datetime.datetime для анализа времени исполнения транзакции
- Функция reference_filter создает выборку транзакций из data в указанном диапазоне reference ('ALL', 'M', 'Y', 'W') с датой date_time
- Функция greetings создает строку приветствия в соответствии с временем суток в date_time
- Функция cards выводит информацию по картам на основе данных data
- Функция top_transactions выводит топ транзакций в месяце с указанной датой из списка data
- Функция currency_rates выводит курс валют в указанную дату в соответствии с user_settings.json
- Функция stock_prices выводит стоимость акций в указанную дату в соответствии с user_settings.json
- Функция calculate_finance выводит кортеж (словарь-затрат, словарь-прибыль) по категориям

В модуле services:
- Функция cashback_benefits принимает на вход список транзакций, месяц и год ответ в формате json сколько на каждой категории можно заработать кешбэка в указанном месяце года.
- Функция investment_bank принимает на вход месяц в формате "%Y-%m" в виде строки, список транзакций и лимит для округления в инвесткопилку (50, 100 или 200руб) и указывает сколько можно отложить денег и инвесткопилку в результате округления до суммы limit
```commandline
# Пример 
Вы настроили шаг округления 50 ₽. 
Покупка на 1712 ₽ автоматически округлится до 1750 ₽, 
и 38 ₽ попадут в «Инвесткопилку». 
Чем активнее расплачиваетесь картой, тем быстрее копятся деньги в копилке.
```
- В функции simple_search Пользователь передает строку для поиска, возвращается JSON-ответ со всеми транзакциями, содержащими запрос в описании или категории.
- Функция phone_search возвращает JSON со всеми транзакциями, содержащими в описании мобильные номера.
```commandline
# Пример 
Я МТС +7 921 11-22-33
Тинькофф Мобайл +7 995 555-55-55
МТС Mobile +7 981 333-44-55 
```
- Функция name_search возвращает JSON со всеми транзакциями, которые относятся к переводам физлицам.
```commandline
# Пример 
Валерий А.
Сергей З.
Артем П.
```

В модуле reports транзакции принимаются в виде датафрейма pandas на выходе функции формируется новый датафрейм pandas:
- Функция spending_by_category принимает на вход: датафрейм с транзакциями, название категории, опциональную дату. Если дата не передана, то берется текущая дата. Функция возвращает траты по заданной категории за последние три месяца (от переданной даты).
- Функция spending_by_weekday принимает на вход: датафрейм с транзакциями, опциональную дату. Если дата не передана, то берется текущая дата. Функция возвращает средние траты в каждый из дней недели за последние три месяца (от переданной даты).
- Функция spending_by_workday  принимает на вход: датафрейм с транзакциями опциональную дату. Если дата не передана, то берется текущая дата. Функция выводит средние траты в рабочий и в выходной день за последние три месяца (от переданной даты).

## Тестирование функций
Тестирование функций производится в модулях пакета tests.

- Протестировать все функции целиком возможно из контекстного меню пакета tests.
- Отдельные функции пакета src возможно протестировать из соответствующих модулей пакета tests.

Дополнительные кейсы для тестирования функций следует писать в соответствующих модулях пакета tests.
